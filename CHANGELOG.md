# Changelog

Изменения рецепта сборки: новые источники, политика, профили, поведение сборки и публикации. Ежедневные обновления данных сюда не включаются — они видны в `domain-changes.json` каждого релиза.

Формат: дата + краткое описание. Проект не использует SemVer для данных, но версионирует релизы по дате сборки.

## 2026-11-13

### Добавлено
- Профиль **Smart** (`blocked-domains-smart.srs`, пресет `routing-smart`): Compact + популярные регистрируемые домены из Full по Tranco top-1M. Compact остаётся строгим подмножеством Smart.
- Zip-поддержка в загрузчике источников (`archive`/`member`) для Tranco.
- Единый реестр наборов `routing/datasets.py`; доменная логика в `routing/domains.py`, сети в `routing/networks.py`.
- JSON Schema для выходных артефактов (`schemas/output/`) и проверка `validate_outputs.py` в CI.
- Ветка `data` с зеркалом наборов (jsDelivr) и git-историей baseline.
- keepalive-workflow против отключения расписания GitHub; авто-issue при сбое сборки; candidate/promote для больших изменений покрытия.
- Ротация сэмплов в мониторинге и `stale-candidates.json` для устаревших записей.
- Лицензии: MIT для кода, CC0 для данных.

### Изменено
- Условные GET-запросы к источникам (ETag/Last-Modified) и кеш `cache/sources` в CI.
- Настраиваемые таймауты/повторы в `policy.json → network`, экспоненциальный backoff.
- requirements-dev.txt со всеми SHA-256 и установка с `--require-hashes`.
- Матрица Python 3.11–3.14 в CI.

### Исправлено
- Бот issue: установка зависимостей, запуск только по событию, обновление своего комментария вместо дублей.
- Удаление git-тегов вместе со старыми релизами; `prune-orphan-tags`.
- Просроченный Direct-review фатален только на PR/push, не роняет плановую сборку.
- Единое `built_at` во всех артефактах.
- Dashboard публикуется даже при сбое мониторинга; история мониторинга не стирается при сбое загрузки.
- Отказ от «первой сборки» diff, если baseline-манифест восстановлен без правил.
