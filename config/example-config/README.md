# Примеры локальных правил

Файлы в этом каталоге являются примерами и **не участвуют в сборке**. Скопируйте нужную запись в `config/manual-vpn.json` или `config/direct-exceptions.json` собственного форка.

- `kind`: `domain` для одного имени, `domain_suffix` для имени и всех поддоменов, `ip_cidr` только для Direct-исключения точного публичного `/32` или `/128`.
- `reason`: проверяемая причина и ссылка на issue/доказательство.
- `review_after`: дата обязательного пересмотра для Direct-исключений.

Public suffixes, общие CDN и личные правила конкретного роутера в общий репозиторий не добавляются. Каждая конфигурация проверяется командой `python scripts/validate_config.py` и при следующей сборке.
